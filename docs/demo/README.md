# Demo: Solidus

`erd.svg`, `erd.xlsx` and `erd.drawio` here were made by `/open-erd:init` on
[Solidus](https://github.com/solidusio/solidus) v4.8.0, an open-source
e-commerce platform for Rails: 105 tables in 14 domains, read from its models
and migrations.

**[Open the interactive ERD](https://tomosia-vietnam.github.io/open-erd/)**:
GitHub's file view shows an SVG as a plain picture, so open it from the site
(or download `erd.svg` and open it in a browser) to search, click and follow
relations.
